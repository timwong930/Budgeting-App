# Budgeting App

A native iOS budgeting app built with SwiftUI to help track income, categorize spending, and manage savings goals.

## Features

- Track income and pay frequency
- Budget across Needs, Wants, and Savings
- Manage category allocations and spending
- Record expenses and savings entries
- Persist budget data locally between launches

## Tech Stack

- Swift
- SwiftUI
- Combine
- Xcode project (`.xcodeproj`)

## Project Structure

- `Budgeting App/` - app source code
- `Budgeting App.xcodeproj/` - Xcode project configuration

## Getting Started

1. Open `Budgeting App.xcodeproj` in Xcode.
2. Select the `Budgeting App` scheme.
3. Choose an iOS Simulator target.
4. Build and run.

## Notes

- Data is stored locally on-device in app documents storage.
- This repository currently targets local development/debug workflows.
